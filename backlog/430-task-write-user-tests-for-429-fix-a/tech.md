tasks_ai/worktree_manager.py:remove_task_worktree removes the Git worktree before calling GitService.is_merged for the task branch. When the CLI runs from the task worktree, GitService defaults commands to context.repo_root, which is the path just removed. The resulting FileNotFoundError aborts archival before cleanup completes. Determine merged state using the main repository root, or evaluate it before worktree removal, then remove the worktree and delete the merged branch safely.
