Critical branches are the actual default branch (main or master) plus testing and staging. The installed pre-receive hook already rejects remote deletion of those names, but local git branch deletion and hammer repo branch delete are not protected. The repo branch delete command currently forwards directly to git branch -d and must explicitly reject critical branches before invoking Git. Local deletion must also be blocked by a git hook that Git runs for branch deletion; determine and use the appropriate hook mechanism available to the project and installed common hooks directory. The task promotion code currently pushes only the task branch for some later states and does not consistently push testing and staging when code crosses those gates. DONE pushes main. Promotion into TESTING must push testing after merge; promotion into STAGING must push staging after merge. Missing local pipeline branches must not silently bypass intermediate gates: they should be recreated from the appropriate base or the transition should fail with an actionable error, and never allow direct-to-main fallback that skips testing or staging. Keep behavior for the resolved actual default branch name rather than hardcoding main.
