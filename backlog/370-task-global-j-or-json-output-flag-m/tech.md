The -j/--json flag is parsed as a per-subcommand, position-dependent option instead of a global directive. It must be accepted in any flag order and by every hammer command combination (tasks, check, repo, guard, and auto-detected tool commands). When present, output must be JSON unconditionally, including on error and usage paths. Requires an inventory of every possible hammer command combination including flags so coverage is exhaustive. Exception: -h/--help stays human-readable text in all cases, so the global JSON directive must not fire for help output.
