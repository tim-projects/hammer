Found while reviewing task 376: after fixing branch content and moving TESTING -> REVIEW, ReviewDiffHook did not rewrite the patch artifacts, so the reviewed patches still contained a superseded version of tasks_ai/commands/modify.py (with committed conflict markers). Receipts match the on-disk patch file, so the gate passed against artifacts that no longer reflected the branch. Root cause areas: tasks_ai/pipeline_hooks.py ReviewDiffHook generation is conditional and generate_file_patches (tasks_ai/audit.py) never prunes patch files absent from the current changed set; after a worktree sync merge the three-dot diff base moves, shrinking the changed set. Workaround used: delete the patches dir plus reviews.json, then 'tasks audit' regenerates.
