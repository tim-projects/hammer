# Refactor Plan: Restore Missing Methods in cli_engine.py

## Problem
After refactoring cli.py to be modular, the list and show commands stopped working because certain methods are missing from tasks_ai/cli_engine.py that are being called by the command modules.

## Root Cause
During the modularization process, some methods were not properly transferred from the monolithic cli.py to the new cli_engine.py module. Specifically:
- Methods called by command modules (like list, show, etc.) are missing from cli_engine.py
- The TasksCLI class in cli_engine.py needs to have these methods restored
- Missing imports (tempfile, subprocess) causing runtime errors
- Signature mismatches between modularized and original methods

## Current Status
Based on testing:
- `./hammer tasks list` works
- `./hammer tasks show <task_id>` works
- `./hammer tasks create` now works after fixing missing tempfile import
- All other CLI commands (modify, move, delete, link, reconcile, cleanup, config, doctor, verify, audit, undo, upgrade, save, restore, current, checkpoint) are working correctly
- The full test suite passes
- No remaining issues or error messages

## Solution Approach

3. Copy the missing method implementations from the original monolithic cli.py.main
4. Add them to cli_engine.py in the appropriate locations
5. Fix missing imports
6. Fix method signature mismatches

## Cleanup Before Merging to Testing
Before merging this branch to testing, perform the following cleanup:

### Cleanup Actions to Perform:
1. **Remove backup files**: Delete any *.bak files created during editing
   - Command: `find . -name "*.bak" -type f -delete`
   - Also delete: `find . -name "*~" -type f -delete`

2. **Remove Python cache directories**: Delete __pycache__ directories and .pyc files
   - Command: `find . -name "__pycache__" -type d -exec rm -rf {} + 2>/dev/null || true`
   - Command: `find . -name "*.pyc" -type f -delete`

3. **Check for debug prints**: Verify no debug print statements remain in code
   - Command: `grep -r "DEBUG:" --include="*.py" . | grep -v "__pycache__" | grep -v ".git"`
   - If any are found, they should be removed

4. **Check for conflict markers**: Ensure no merge conflict markers remain
   - Command: `grep -r "<<<<<<<" --include="*.py" . | grep -v "__pycache__" | grep -v ".git" || grep -r "=======" --include="*.py" . | grep -v "__pycache__" | grep -v ".git" || grep -r ">>>>>>>" --include="*.py" . | grep -v "__pycache__" | grep -v ".git"`
   - If any are found, they must be resolved before proceeding

5. **Run final validation**: Execute the full test suite to confirm everything works
   - Command: `./hammer check all`

### To Create a Cleanup Script:
You can create a script at `.kilo/cleanup_before_merge.sh` with the following content:
```bash
#!/bin/bash
# Cleanup script to run before merging branch to testing

echo "Starting cleanup before merging to testing..."

# 1. Remove backup files
echo "Removing backup files (*.bak)..."
find . -name "*.bak" -type f -delete
find . -name "*~" -type f -delete

# 2. Remove __pycache__ directories
echo "Removing __pycache__ directories..."
find . -name "__pycache__" -type d -exec rm -rf {} + 2>/dev/null || true

# 3. Remove .pyc files
echo "Removing .pyc files..."
find . -name "*.pyc" -type f -delete

# 4. Verify no debug prints remain (informational)
echo "Checking for potential debug prints..."
if grep -r "DEBUG:" --include="*.py" . | grep -v "__pycache__" | grep -v ".git"; then
    echo "WARNING: Potential debug prints found. Please review:"
    grep -r "DEBUG:" --include="*.py" . | grep -v "__pycache__" | grep -v ".git"
else
    echo "No obvious debug prints found."
fi

# 5. Check for conflict markers
echo "Checking for conflict markers..."
if grep -r "<<<<<<<" --include="*.py" . | grep -v "__pycache__" | grep -v ".git" || \
   grep -r "=======" --include="*.py" . | grep -v "__pycache__" | grep -v ".git" || \
   grep -r ">>>>>>>" --include="*.py" . | grep -v "__pycache__" | grep -v ".git"; then
    echo "ERROR: Conflict markers found! Please resolve before proceeding."
    exit 1
else
    echo "No conflict markers found."
fi

# 6. Run final validation
echo "Running final validation check..."
./hammer check all

echo "Cleanup complete. Branch is ready for merging to testing."
```
Then make it executable with: `chmod +x .kilo/cleanup_before_merge.sh`

After cleanup, the branch will be ready for merging to testing.
